# Personal Expense Tracker

A simple, menu-driven Personal Expense Tracker developed using Python. This application helps users manage their daily expenses and understand their spending habits.

## Features

- **Add Expenses:** Record expense amount, category, description and date.
- **View Expenses:** Display all recorded expenses.
- **Delete Expenses:** Remove unwanted expense records.
- **Expense Report:** Calculate total expenditure and average spending.
- **Category-wise Analysis:** View expenditure for individual categories.

## Technologies Used

- Python 3
- Lists and Dictionaries
- Conditional Statements
- Loops
- Built-in Python Functions
